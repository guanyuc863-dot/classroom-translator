# 课堂翻译 · iPad 网页版

上课用的实时字幕：iPad 录音 → 语音识别 → 大模型翻译，附带课堂总结、私下问答和课堂录音。整个程序就是这个网页，不需要电脑。

## 使用

1. 在 iPad 的 Safari 打开本页网址，点 **分享 → 添加到主屏幕**，以后从主屏幕图标打开。
2. 点右上角 **设置**，选两项服务，各填一次密钥，然后点 **测试连接**：
   - **翻译、总结和问答**：OpenAI、DeepSeek、豆包（火山方舟）、通义千问、Kimi、硅基流动，或任何 OpenAI 兼容接口。
   - **语音识别**：OpenAI、Groq、硅基流动、豆包语音（火山引擎），或任何 OpenAI 兼容接口。
3. 点 **开始录音**。录音时让页面留在前台。想把字幕放在课件旁边，就用分屏或 Slide Over，再点 **大字幕**。
4. 下课后，点字幕前面的时间，就从那一句开始听录音。在 **以前的记录** 里可以导出文字记录（Markdown）和录音（WAV）。

## 隐私

- 密钥只保存在你这台设备的浏览器里。请求从设备直接发给你选的服务，不经过其他服务器。
- 网页本身不收集、不上传任何数据。
- 课堂记录、笔记和录音都保存在设备上。
- 同一个麦克风上的语音提问不会录进课堂录音，那一段是静音。

## 费用

使用的是你自己的服务账号：

- 语音识别按音频时长计费，只上传有人说话的片段。
- 翻译、总结、问答按 token 计费。

建议在服务商后台给密钥设置用量上限。
