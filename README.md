# 课堂翻译 · iPad 网页版

上课用的实时字幕：iPad 录音 → OpenAI 语音识别 → GPT 翻译，附带课堂总结和私下问答。整个程序就是这个网页，不需要电脑。

## 使用

1. 在 iPad 的 Safari 打开本页网址，点 **分享 → 添加到主屏幕**，以后从主屏幕图标打开。
2. 点右上角 **设置**，填自己的 OpenAI API Key，点 **测试连接**。
3. 点 **开始录音**。录音时让页面留在前台；想把字幕放在课件旁边，用分屏或 Slide Over，再点 **大字幕**。

## 隐私

- API Key 只保存在你这台设备的浏览器里，请求从设备直接发给 OpenAI，不经过其他服务器。
- 网页本身不收集、不上传任何数据。
- 课堂记录和笔记保存在设备上，可以在“以前的记录”里导出成 Markdown。

## 费用

使用的是你自己的 OpenAI 账号：

- 语音识别按音频分钟计费（只上传有人说话的片段）；
- 翻译、总结、问答按 token 计费。

建议在 OpenAI 后台给这个密钥设置用量上限。
