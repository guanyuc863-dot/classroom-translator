# 课堂翻译（网页版：iPad / Mac / Windows）

上课用的实时字幕：录音 → 语音识别 → 大模型翻译，附带课堂总结、私下问答和课堂录音。整个程序就是这个网页，不用安装别的东西。

打开：<https://guanyuc863-dot.github.io/classroom-translator/>

## 装成应用（推荐）

- **Mac / Windows，用 Chrome 或 Edge**：打开上面的网址，点地址栏右侧的“安装”图标（或页面上的“安装到这台电脑”）。之后桌面、开始菜单或启动台里会有“课堂翻译”，在单独的窗口里打开。
- **Mac，用 Safari**：菜单栏点 文件 → 添加到程序坞。
- **iPad**：在 Safari 里点 分享 → 添加到主屏幕。

用 Safari 装成的应用（Mac 程序坞、iPad 主屏幕）和浏览器分开保存数据，打开后要重新填一次密钥。

## 第一次用

1. 点右上角 **设置**，选两项服务，各填一次密钥，然后点 **测试连接**：
   - **翻译、总结和问答**：OpenAI、DeepSeek、豆包（火山方舟）、通义千问、Kimi、硅基流动，或任何 OpenAI 兼容接口。
   - **语音识别**：OpenAI、Groq、硅基流动、豆包语音（火山引擎），或任何 OpenAI 兼容接口。
2. 在电脑上可以选 **声音来源**：
   - **麦克风**：教室上课。
   - **电脑声音**：网课、视频会议、视频。开始录音时，选课程所在的标签页并打开“共享标签页音频”。
3. 点 **开始录音**。

## 上课时

- **悬浮字幕**（电脑上的 Chrome、Edge）：弹出一个置顶的小字幕窗，可以拖到课件或网课画面上。
- **大字幕**（iPad 或窄窗口）：只看大号字幕，适合分屏放在课件旁边。
- **问这句**：选几句字幕私下提问，回答会注明出处。
- **新录音**：这一份保存好，马上开始新的一份。
- **下课后**：点字幕前面的时间，就从那一句开始听录音。在 **以前的记录** 里可以导出文字记录（Markdown）和录音（WAV）。

## 隐私

- 密钥只保存在你这台设备的浏览器里。请求从设备直接发给你选的服务，不经过其他服务器。
- 网页本身不收集、不上传任何数据。
- 课堂记录、笔记和录音都保存在设备上。
- 同一个麦克风上的语音提问不会录进课堂录音，那一段是静音。

## 费用

使用的是你自己的服务账号：

- 语音识别按音频时长计费，只上传有人说话的片段。Groq 最便宜，约 0.04 美元/小时；OpenAI 约 0.003 美元/分钟。以官网为准。
- 翻译、总结、问答按 token 计费。

建议在服务商后台给密钥设置用量上限。
